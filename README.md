# Achadinhos da Vic

Grupo de ofertas no WhatsApp: achadinhos de Mercado Livre, Amazon e Shopee, filtrados.

- [Vic Site/](Vic%20Site/) — página de entrada do grupo (botão de convite).
- [ml-afiliados/](ml-afiliados/) — bot que coleta as ofertas, gera os links de afiliado e posta no grupo. Veja o [README do bot](ml-afiliados/README.md).
